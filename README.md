# Solusi Sampah di Pantai Bengkulu

Website ini dibuat sebagai project kelompok untuk memberikan informasi mengenai permasalahan sampah di kawasan Pantai Bengkulu serta solusi yang dapat dilakukan untuk menjaga kebersihan lingkungan pantai.

## Deskripsi Project

Website ini berisi informasi tentang:

- Penyebab terjadinya penumpukan sampah di pantai
- Dampak sampah terhadap lingkungan dan wisata
- Solusi penanganan sampah
- Hasil olahan sampah menjadi produk bernilai
- Galeri dokumentasi kondisi pantai

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript (jika ditambahkan ke tahap berikutnya)

## Tujuan

Meningkatkan kesadaran masyarakat terhadap pentingnya menjaga kebersihan pantai serta mendorong pengolahan sampah menjadi barang yang bermanfaat.
